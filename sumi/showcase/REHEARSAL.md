# デモの検証記録

- Stageshow の `form-error` を構成・動きの参照にし、Sumi の配色と日本語の文書処理に合わせて変更した。各シーンは実処理ではない画面演出で、入力可能な比較欄だけがその場で文字列を計算する。
- 1440pxと390pxの Chromium でページ全体と動作の少ない表示を確認。比較欄は、後半の指定語で「先頭だけは検出なし／全文は検出」、冒頭の指定語で両方「検出」を示した。横方向のはみ出しはなかった。
- ７つの演出が順に終了状態まで進むことと、ページの JavaScript エラーがないことを確認した。
- Stageshow film の代表場面はデスクトップと390pxで `rehearsal passed`。ただし各撮影にフレーム計測の欠落があり、全コマの動きについては `inconclusive` だった。実機スマートフォン・他ブラウザでは未確認。
- 生成ページは `npm run build` で `dist/showcase/` に出力する。`document-proof/` は別のビルドが必要なため、ローカルのクリーンビルドではそのリンク先を別途用意する。公開ページの演出は暗号処理やLeanの証明を代わりに実行しない。
