# 実行権限の境界プラグ

`npm run demo:capability-gate` は、架空の学校の文書公開と倉庫の商品ピックアップについて、上限超過を拒否し、許可された一回を模擬実行し、注文の再利用を拒否します。外部サービスやロボットには接続しません。

ホワイトボードの「外部の指示やモデル出力で操作権限を増やさない」という構想を、小さな実行境界として実装しています。信頼された発行者が、ゲート、操作、対象、数量上限、期限、一回限りの注文 ID を署名します。ゲートは、所有者が別途設定した公開鍵と必要署名数で検証し、AI が提案した操作を注文と比較してから実行します。署名は独立した ECDSA 署名の組であり、閾値署名ではありません。

このプラグが示すのは、署名を信頼する従来方式と、ZK や FHE を使う検証可能な計算を接続する際にも、実行権限を別の信頼境界として設ける考え方です。現在、このゲートは ZK 証明や FHE の計算結果を検証していません。署名済みの条件そのものは公開され、発行者が正当な注文を発行したことも、物理世界の操作や入力が正しいことも証明しません。

使用済み注文の記録はプロセス内だけです。再起動や別インスタンスをまたぐ再利用、強制を迂回する直接操作、鍵の失効、発行者の侵害を防ぐものではありません。実運用には信頼できる時計、耐久性のある原子的な使用済み管理、実行経路の強制、鍵管理と、物理的な安全装置が別途必要です。実行が失敗しても注文は消費されます。
