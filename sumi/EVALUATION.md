# 架空データを使ったマスクの検査

`npm run evaluate:masking` は、`evaluation/masking-cases.json` にある架空の文書を加工し、指定した文字列がそのまま残っているかを確認します。氏名やメールなどの例に加え、健康情報や生徒番号のように、現在の検出が苦手な例も含めています。対照文は、加工の必要がないと仮定した短い例です。

この検査は開発中に用意した少数の例であり、実際の学校文書に対する検出率ではありません。文字列が消えた場合でも、一部の文字や文脈から推測される可能性があります。逆に、対照文が変わらなくても、他の文章で不要な加工が起きないとは言えません。正式な評価には、収集と利用に同意を得たデータまたは適切に作られた独立データ、評価基準、見落としと過剰加工の両方の検討が必要です。

非公開にしたい語句を利用者が追加する例も含みます。これは事前に何を隠すか分かっている場合の補助であり、自動検出の性能には含めずに解釈します。結果は確認の補助で、マスク後の全文を人が確認する必要があります。
